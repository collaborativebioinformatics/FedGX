# Python:           3.10+

# PLINK/PLINK2:     v1.9+ or v2.0+ (for PLINK binary format support)
#
# On Ubuntu/Debian:
#   sudo apt update
#   sudo apt install -y build-essential python3-dev python3-venv git tmux
#   sudo apt install -y nvidia-cuda-toolkit nvidia-utils  # if GPU available
#
# For NVIDIA GPU support on Brev/cloud instances:
#   nvidia-smi  # verify GPU availability
#   Install CUDA 11.8+
#   Install cuDNN 8.0+

# ============================================================================
# INSTALLATION INSTRUCTIONS
# ============================================================================
# 1. Create and activate a virtual environment:
#    python3 -m venv venv_nvflare
#    source venv_nvflare/bin/activate
#
# 2. Install this requirements file:
#    pip install -r requirements.txt
#
# 3. Verify key installations:
#    nvflare --version
#    python3 -c "import torch; print(torch.__version__)"
#    regenie --help  # if REGENIE is in PATH
#
# 4. For federated learning on Brev instances:
#    - Ensure one venv per NVFLARE client instance
#    - Use tmux to persist sessions during long jobs
#    - Configure AWS credentials (IAM role recommended over static keys)
#    - Validate GPU with: nvidia-smi
#
# 5. To generate synthetic data locally:
#    bash Scripts/generateData.sh
#    # Produces 3 sites with ~500K SNPs, ~100K samples each

# ============================================================================
# NOTES
# ============================================================================
# - REGENIE, GWAMA, LDAK, and PLINK are compiled binaries and must be
#   installed separately. Add them to your PATH or reference by full path.
# - GPU support requires CUDA 11.8+ and cuDNN 8.0+
# - For production federated runs, ensure NVFLARE security certificates
#   are properly configured via the dashboard.
